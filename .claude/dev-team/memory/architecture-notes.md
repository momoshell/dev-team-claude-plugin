- **2026-08-01** — **ADR-006 Amendment 1 (proposed): task artifacts relocate out of `.claude/` to `~/.dev-team/tasks/<repo-slug>/<task-slug>/`**, with parent-side-only state at `~/.dev-team/state/<task-slug>/` (completion nonces, EXIT sentinels, hook attestation, per-task worker-plugin snapshot) which is never `--add-dir`'d. Status: proposed.
- **2026-08-01** — **ADR-003 Amendment 1 (proposed): the completion token is an unguessable per-dispatch nonce**, delivered to the adapter via a mode-0600 file outside the task dir that the adapter reads and unlinks before spawning `claude`; never in the worker's env/argv/kickoff/role body/task dir. Parent re-derives completion from the ladder (fresh schema-valid return) on **every** wake regardless of which token released it — a forged wake buys one wasted loop iteration, never a false completion. Attention channel is orthogonal to the ladder, never completion evidence, **and best-effort by construction** (`signals/` file + ladder carry all guarantees). Rank-2 EXIT sentinel moves to parent-side state and is permanent (no process-exit event in cmux 0.64.20). Status: proposed.
- **2026-08-01** — **ADR-005 Amendment 1 (proposed; extends the recorded D9 entry): `--tools` is identical across all worker roles (`Read,Edit,Write,Glob,Grep,Bash`); profiles differ only in `--allowedTools`.** Judgment roles keep Bash + the built-in read-only set (`git log`/`diff`/`grep`) + the two cmux allows — retiring the hook-relay emitter, leaving exactly one emitter (the worker) for every role. The `git status --porcelain` post-condition is unconditional for **all** roles (live escape vector is `Bash(npm test *)` spawning repo-controlled scripts — an executor capability), reset scoped strictly to the worker's own worktree, primary-checkout dirt escalates never auto-resets, residual (writes outside the repo) stated. Status: proposed.
