- **2026-08-01** — Validators: **throw on contract-author error, return violations on data error** (`scripts/cmux/contract.mjs` precedent). Throw when the *schema* is wrong — out-of-budget keyword, malformed keyword **value shape** (`required: 'name'`, `additionalProperties: 'no'`, `items: true`) — because that's a repo-author error no valid data can trigger; return `Violation[]` when the *instance* is wrong, because the caller is the dispatcher's hot path and needs to classify (`invalid_return`), not crash. *Why:* the deep review caught the value-shape half missing — name-only checks let `additionalProperties: 'no'` silently disable closed-set enforcement, the exact vacuous-validator failure. Shape-check keywords before recursing.
- **2026-08-01** — `Violation` shape is `{ path, keyword, message }` (`path` dotted/bracketed from `$`; `keyword` = the failed budget keyword or the distinct `schema_version_too_new`). *Why:* a test asserting only "non-empty violations" can't tell a right-reason rejection from a reject-everything validator — negatives must assert `path` + `keyword`, ideally exactly-one via deepEqual.
- **2026-08-01** — A slug that feeds a filesystem path **throws on empty/degenerate input**, never returns a fallback (`slugify` in `contract.mjs`). *Why:* an empty segment collapses a path (`~/.dev-team/tasks//x`) and silently re-targets writes; fail closed at derivation, not at the write.
- **2026-08-01** — Cross-test-file constant agreement is guarded by **source-text extraction, not import**: `import`ing another `test/*.test.mjs` re-registers its whole suite (node:test registers at import time). Read the file with `readFileSync` and regex the literal — the established idiom (`schema.test.mjs`/`agents.test.mjs` workflow-source scans, now the BUDGET drift guard in `test/cmux-contract.test.mjs`).
- **2026-08-02** — `cmux send` does **not** auto-submit, even with a trailing `\n` — every kickoff is `send` then `send-key <surface> enter` (live-verified, spike S7; implemented in `cmuxctl.mjs` `sendLine`). *Why:* a missing `send-key` looks exactly like a hung worker.
- **2026-08-02** — Text sent into a cmux pane is **typed into a live shell** — the one shell-injection boundary in cmux mode. `sendLine` enforces an allowlist charset over the whole line (refusing `\r` — CR *is* Enter in a PTY — all C0, and shell metacharacters) and refuses rather than escapes. *Why:* `task_artifacts_root` is user-configurable; fail closed at the boundary.
- **2026-08-02** — Permission-rule construction: ctx paths already start with `/`, so the rule builder prepends exactly **one** slash (`Edit(//${p}/**)` with an absolute `p` would emit `///`).
