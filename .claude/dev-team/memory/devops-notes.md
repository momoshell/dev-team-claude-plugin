## Entries

- **2026-08-01** — CI is a single GitHub Actions workflow, `.github/workflows/test.yml`: checkout → Node 20 → `node --test`, on every push and PR. *Why:* orients devops-lead to the entire CI surface — there is no build/deploy pipeline beyond this. Source: `.github/workflows/test.yml`. [deprecated — supersedes: see the 2026-08-08 matrix entry below]
- **2026-08-08** — CI is now a **two-leg Node matrix** (`node-version: ["20", "24"]`, `fail-fast: false`, stable job names `test (node <v>)`) in the same single workflow — still bare `node --test`, still no build/deploy pipeline. The `24` leg exercises `scripts/factory/*` (Node ≥ 24 floor, ADR-024); the `20` leg proves the rest of the repo's Node 20 promise AND runs the factory floor-refusal tests (zero-skip file). The literal `24` is a bidirectional contract with `ledger.mjs`'s `NODE_FLOOR` — neither moves alone; `test/factory-env.test.mjs` pins the matrix shape, the `with:`-side matrix consumption, and the `run: node --test` step by regex over raw text (no YAML parser exists or may be added). *Why:* a matrix entry that spawns but doesn't consume the variable, or a workflow that stops running the suite, is CI-green while testing nothing. Supersedes the 2026-08-01 single-job entry. Source: issue #40, do-40-02.
- **2026-08-08** — This repo has **no branch protection and no rulesets** on `main` (verified via the GitHub API). Two consequences: renaming/adding CI jobs can never orphan a required status check (job-name churn is free), and nothing mechanically blocks a merge on red CI — a green run is a human responsibility. A least-privilege `permissions: contents: read` block on the workflow is a known cheap follow-up, deliberately kept out of #40's scope. *Why:* both facts keep getting re-derived at planning time. Source: issue #40 planning, API check 2026-08-08.
- **2026-08-01** — `hooks/hooks.json` wires a `SessionStart` hook that injects `orchestration.md` (+ referenced files) into every session. *Why:* this is the mechanism that makes the plugin's orchestration rules active at all — changes here are high-blast-radius (affects every session, every project with the plugin enabled). Source: `hooks/hooks.json`, README.md.
