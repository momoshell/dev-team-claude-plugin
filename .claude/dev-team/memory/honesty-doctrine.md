description: Unknown is null with one closed reason; session-file write failures fail the turn
metadata:
  type: feedback
---

An unmeasured value is null with a reason, never a guess and never a zero. Rates carry their denominator. Journal and session writes do not normally fail the caller. One exception: a failed session-file write fails the turn (`crew/lean.mjs`, `guardedAppend`), as the operator decided on 2026-11-12. A tool that cannot measure something prints that it could not, rather than reporting a clear.
