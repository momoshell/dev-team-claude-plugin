## The ask

PR 2022 added `crew finish <lane>`: it finishes a stopped lean lane and stops committed and rebased, with a
`finish-ready` row and nothing pushed. Add the operator's decision on a ready lane, as ADR-051 section 3 describes:

- `crew finish <lane> --accept [--notes <file>]` publishes the PR, with the operator's notes under their own heading
  in the body.
- `crew finish <lane> --return <file>` runs one more finish pass with the file's guidance as the builder's triage
  input.
- `crew finish <lane> --abandon` ends it; nothing is published.

Each decision is a `finish-decision` journal row with the choice and the notes' sha256 digest (null when no notes).
A green finish run also writes one fused finish report, so the deciding session reads it instead of the journal.

Invariants:
- A decision verb acts only on a lane whose last run ended `finish-ready` and that has no decision since.
- `--accept` publishes exactly the subject and body the finish run measured, plus the notes; merging stays the
  operator's.
- After `--accept`, `crew closeout <lane>` accepts the lane (it reads the journal's last `pr` row).
- A `--return` pass counts against the finish run's three-round review cap; it never grants new rounds.
- `crew finish <lane>` with no flag behaves exactly as today.
