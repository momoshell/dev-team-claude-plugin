# Absent is not zero

A zero is a measurement; absence means no measurement was obtained. Never
fabricate zero for an unknown value. Represent absence explicitly, with one
closed reason where the contract provides one; if it does not, say so.

Partial token or cost records can be mistaken for complete ones. Pin both an
unmeasured absence and a genuinely measured zero. Explain what was missing and
why; an emitter that never ran is an absence, not a failed write. Distinguish
retired counts from genuinely empty ones.
