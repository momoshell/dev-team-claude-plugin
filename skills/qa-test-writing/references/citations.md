# Citation discipline

Cite a file by path and a code site by symbol, never by line number. Comments
citing another file follow the same rule. Every cited path must name an existing
tracked file; check it before returning. If a citation goes stale, move it, not
the file. Repoint it to a kept exhibit or drop the claim; do not cite a
mechanism that no longer exists.
